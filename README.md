<p align="center">A mobile-first prototype helping students find flexible part-time jobs, internships, and remote work.</p>

---

## 🚀 Overview

![](<https://github.com/nastaj/DA5-Project/blob/main/sprints_1_2/Setup%20student%20profile%20(step%203).png>)

DreamWork is a student-focused job search application designed to make finding flexible work easy and accessible. The project is being developed as part of an Agile SCRUM academic module, focusing on prototyping, user-centered design, and iterative planning.

This repository contains:

- Source files (prototype code or mock backend, if applicable)
- Figma design exports
- Documentation
- Agile artefacts and links (Jira, OneNote)

---

## 🧩 Features (Planned & Implemented)

### **MVP Features**

- 🔐 User Registration & Login
- 👤 Profile Management (skills, availability, location)
- 🔍 Job Search & Filtering
- 📄 Job Details View
- 🧭 Smart Job Recommendations
- 📊 Application Tracker (Applied → Interviewing → Hired → Rejected)

### Optional Features (Released)

- ⭐ Saved Jobs
- 🔔 Notifications

### **Optional Features (Stretch Goals)**

- 🌍 Localization
- 🦽 Accessibility Options
- ✉️ Employer messaging
- 📱 Android / iOS compatibility
- 🎧 Support for screen readers

---

## 📅 Agile Process

This project follows the **SCRUM framework**, with:

- 6 total sprints (2 per week)
- Backlog managed in Jira
- Sprint burndown charts
- Release planning
- Daily Scrum, Sprint Review, Sprint Retrospective
- Definition of Ready (DoR) and Definition of Done (DoD)
- Story points estimated using Planning Poker (1, 3, 5, 7, 10)

---

## 📆 Sprint Breakdown

| Sprint | Focus                                  |
| ------ | -------------------------------------- |
| 1      | Student Auth, Job Search, Profile      |
| 2      | Smart Suggestions, Job Details         |
| 3      | Job Apply, Employer Auth, Track Status |
| 4      | Notifications, Saving Listings         |
| 5      | Posting Listings, Navigation           |
| 6      | Password Security, Performance, Fonts  |

Full documentation available in the PDF report.
